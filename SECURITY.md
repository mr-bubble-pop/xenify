# Security

Xenify was written by AI and has not been reviewed line by line by a person
(see "How Xenify was made" in the [README](README.md)). Reports of security
problems are very welcome.

## Reporting a problem

Please report security problems **privately**, not in a public issue: open
the repository's **Security** tab on GitHub and choose **Report a
vulnerability**. Include what you found, how to reproduce it, and which
version and app (or server) it affects.

You'll get a reply as soon as possible. Fixes go out through the normal
updates (Xenify Hub and the server's own updater), and the report is
credited unless you'd rather it wasn't.

## Supported versions

Only the latest release gets security fixes.
