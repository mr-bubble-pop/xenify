# Xenify proofing corpus

Synthetic English passages for **grammatical error detection and correction**,
built to train and test [Xenify](https://github.com/)'s offline grammar checker
(`xenify-grammar` and its mistake spotter). Released so anyone can retrain,
evaluate or build on it.

## What's in it

| File | Rows | What |
|---|---:|---|
| `train.jsonl` | 48,377 | Passages with one planted mistake, and correct passages (standard and informal) |
| `test-dev.jsonl` | 3,255 | Development test set (same generator as train, different runs) |
| `test-heldout.jsonl` | 3,201 | Held-out test set, never used while developing |
| `test-independent.jsonl` | 3,608 | Written by a **different** model (gpt-oss-120b), for an honest score |
| `soundalikes.jsonl` | 79,337 | Correct example sentences for 278 sets of sound-alike words (beer/bear/bare…) |
| `reviews/*.jsonl` | | Our decision on every pair where the two checkers disagreed |

Each passage (JSON lines):

```json
{"id": "err:workplace_email:missing_word:native:3#2", "setting": "workplace_email",
 "register": "standard", "error_type": "missing_word",
 "text": "We need finish the migration before Friday.",
 "corrected": "We need to finish the migration before Friday.",
 "mistakes": [{"wrong": "need finish", "fix": "need to finish"}]}
```

Correct passages have no `error_type`, `corrected` or `mistakes`; informal ones
list their deliberate `features` (slang, texting, African American English,
regional dialect, spoken spellings…), which are **not** mistakes.

- **30 kinds of mistake**: agreement, verb forms, pronoun case, its/it's,
  sound-alikes, confused words, real-word typos, eggcorns, missing/wrong
  articles, prepositions, verb patterns, plurals, comparatives, missing and
  repeated words, word order, commas (around names, after openers, in lists,
  splices), apostrophes, capitalisation, hyphens, fragments, tense shifts,
  pronoun reference, email sign-offs, spelling.
- **16 writing settings**: academic paper, school essay, workplace email,
  formal letter, technical docs, news, marketing, cover letter, professional
  and personal social posts, video comments, group chats, forums, product
  reviews, public notices, fiction.
- **Two voices** for mistakes: a native speaker typing quickly, and a fluent
  English learner.

## How it was made

1. **Written** by `deepseek/deepseek-v4-flash` (MIT-licensed weights) from our own
   prompts and our own list of mistake kinds and settings (prompts:
   `src/ai.rs`, `src/taxonomy.rs`, `src/sounds.rs` in the Xenify repository). The
   independent test set was written by `openai/gpt-oss-120b` (Apache-2.0).
2. **Checked twice** by models from different families: `qwen/qwen3-235b-a22b-2507`,
   then `openai/gpt-oss-120b` (or `deepseek/deepseek-v4-pro` for text gpt-oss wrote).
   - Training data: a passage with a mistake, or a correct standard-English
     passage, is kept only if both checkers pass it; correct informal passages
     need only the first, because the second checker wrongly treats dialect
     and slang as errors. (50,654 passed the first check; 48,377 are kept.)
   - Test data: where the checkers disagreed, a person-in-the-loop review (by
     Claude, recorded in `reviews/`) decided.
3. **Scanned** for quotations: every passage quoting a real, well-known person
   (authors, philosophers, public figures — 29 in all, old or new) was removed.
   Book and speech titles, and invented people, remain.

All model calls went through OpenRouter's zero-data-retention endpoints.

## Known limits

- **AI-written.** It reads like AI text: tidy, mid-length, a little generic.
  Real writing is messier.
- **One mistake per passage** (the training script also joins passages to
  make multi-mistake paragraphs).
- **Some labels are still wrong.** About 22% of generated pairs failed the first
  check and ~6% of the rest failed the second; double-checking catches most, not
  all. Scores on these test sets carry a few percent of noise.
- English only; mostly US spelling. The training script respells about a
  quarter of the passages the UK/Australian way (colour, organise, travelled)
  so models don't treat either as a mistake.
- "Correct" informal passages reflect the generator's idea of each register;
  they are not authoritative descriptions of any dialect.
